## Business Outcome

Build a coding agent in plain Python on the real tool-calling API: four tools, approval
gates, budget and stuck stop rules, a ReAct loop, a judge with Reflexion, and an MCP
server. Use it to fix the bug in `fixture/`, record two runs, then compare it with a
vendor agent (Claude Code) given the same bug. Graded out of 100 per `RUBRIC.md`.

Non-goals: extra features, larger models, extra runs, any change to given files
(`agent/core.py`, `provider.py`, `toolbox.py`, `trace.py`, `testrunner.py`, `cli.py`,
`fixture/`, `judge/`, `tests/`). The grader restores those, so edits there do nothing.

## Tailoring

This is a single-developer, no-production, no-regulated-data assignment. AISE stages
03-scaffold and 06-deployment are NOT_APPLICABLE_WITH_REASON: the starter provides the
skeleton and there is no deployment; "release" means pushing the repository for grading.
Data classification: public course material, synthetic fixture data, no PII. The only
secret is the API key in `.env`, which `.gitignore` excludes.
