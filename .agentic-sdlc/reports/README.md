Reports are views over canonical records, artifacts, and ledgers. When practical, they should include the command, timestamp, source workspace, record IDs, evidence IDs, schema version, and report-render contract used to generate or reconcile the report.

Strict release should not rely on report prose alone. Material report claims need canonical record IDs, evidence ledger records, acceptable evidence states, freshness, and contradiction/supersession checks.
