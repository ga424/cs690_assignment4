# Stage Feedback

Use this directory for structured downstream-to-upstream defects.

Feedback should include:

- Feedback ID.
- Source stage and target stage.
- Affected artifacts and evidence IDs.
- Expected contract.
- Observed defect, ambiguity, or contradiction.
- Severity: BLOCKER, MAJOR, MINOR, or ADVISORY.
- Recommended owner and next action.
- Whether the downstream stage stopped, continued with conditions, or needs human authority.

Do not silently repair upstream meaning inside a downstream artifact.
